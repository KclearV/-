## 记录规则

1. 文件命名采用 `YYYY-MM-DD-空间或主题.md`；日期按北京时间，历史事项使用实际发生日期，未知日期标为待补充。
2. 每条记录区分“想法”“待确认”“已确定”“已实施”；只有用户明确确认后才写入最终决定。
3. 保留原始描述、图片或文件来源；新方案注明替代的旧方案，不静默覆盖历史决定。
4. 图片放在所属分类的 `附件/` 中，以相对链接插入记录。标明拍摄位置、日期、方向及尺寸单位；未知信息不推测。
5. 更新本页待办，并在相关分类保存详细记录；没有提供的信息标为待补充。
6. 保存到 GitHub 前检查仓库可见性；合同、地址、电话、证件及付款信息先脱敏。
